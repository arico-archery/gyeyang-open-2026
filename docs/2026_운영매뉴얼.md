## 1. 전체 구조 한눈에 보기

본 시스템은 4개의 외부 서비스가 연결된 구조입니다. 각 역할을 이해하면 운영 중 발생하는 문제의 원인을 빠르게 짚어낼 수 있습니다.

```
[ 사용자 ]
    │
    ▼
┌──────────────────────────────┐
│ www.gyeyangopen.com (Vercel) │  ← 사이트 + 앱이 모두 여기서 실행
└──────────────────────────────┘
    │            │              │
    ▼            ▼              ▼
[Supabase]   [SmugMug]      [ianseo]
공지·푸시·   대회 사진      선수 명단·결과
관리자 권한                  (대회 종료 후 자동 보존)
```

**서비스별 역할**

| 서비스 | 역할 | 데이터 |
|---|---|---|
| **Vercel** | 사이트·앱이 동작하는 서버 | 코드 (GitHub와 자동 연결) |
| **GitHub** | 코드 저장소 | https://github.com/arico-archery/gyeyang-open-2026 |
| **Supabase** | 사용자 계정·공지·푸시 구독 등 데이터베이스 | 텍스트 데이터 |
| **SmugMug** | 대회 사진 호스팅 | 사진 파일 |
| **ianseo** | 국제 양궁 기록 시스템 (외부) | 선수 명단·결과 (자동 가져옴) |

**핵심 원리**: 사이트와 앱은 같은 코드 베이스이며, `/app/...` URL은 참가자 앱, 나머지는 홈페이지입니다. 사진·결과 같은 외부 데이터는 자동 동기화되므로, 운영진이 직접 손대야 하는 곳은 **공지사항·푸시·사진 업로드** 세 곳입니다.

## 3. 공지사항 작성·푸시 알림

가장 자주 쓰게 될 기능입니다. 공지는 **사이트의 모든 사용자**에게 즉시 노출되며, 「푸시 알림 보내기」 체크 시 **앱을 설치한 사용자에게 푸시**까지 전송됩니다.

### 3-1. 공지 작성 단계

1. **관리자 로그인**: https://www.gyeyangopen.com/app/admin
2. 「공지사항 관리」 카드 클릭
3. 우상단 「+ 새 공지」 버튼
4. 입력:
   - **제목**: 한국어
   - **제목 (영문)**: 영어 (선택, 비워두면 한국어 그대로)
   - **본문**: 한국어
   - **본문 (영문)**: 영어 (선택)
   - **중요도**: `normal` / `important` / `urgent` (선수 앱에서 색상 배지로 표시)
5. **「푸시 알림 보내기」 체크박스** — 체크 시 모든 구독자에게 즉시 푸시
6. 「저장」 버튼 → 공지가 즉시 사이트·앱에 노출됨

### 3-2. 공지 톤 가이드

- **normal**: 일반 안내 (개회식 시간 안내 등)
- **important**: 중요 안내 (일정 변경, 식사 시간 등) — 앱에서 노란 배지
- **urgent**: 긴급 안내 (날씨로 인한 취소 등) — 앱에서 빨간 배지

푸시는 한 번 보내면 취소할 수 없으니, 본문을 한 번 더 확인 후 체크박스를 누르세요.

### 3-3. 푸시 알림 End-to-End 테스트 (운영 전 1회 권장)

대회 운영 전에 **반드시 한 번 테스트**해서 푸시가 정상 작동하는지 확인합니다.

**테스트 절차**:

1. 테스트용 스마트폰에서 `https://www.gyeyangopen.com/app`을 Safari/Chrome으로 열기
2. 「홈 화면에 추가」(iOS) 또는 「설치」(Android) — PWA 설치
3. 홈 화면 아이콘으로 앱 실행 → 회원가입/로그인
4. 첫 접속 시 「알림 허용」 권한 요청 다이얼로그가 뜨면 **허용**
5. (만약 권한 요청이 안 떴다면) `/app/notifications` 페이지에서 「알림 켜기」 버튼
6. 관리자 페이지에서 테스트 공지 작성 → 「푸시 알림 보내기」 체크 → 저장
7. **1~5초 안에 디바이스에 알림이 뜨면 성공** ✓

**iOS 특이사항**: iOS 16.4 이상에서만 PWA 푸시가 동작합니다. iPhone X 이상이면 iOS 16.4+로 업데이트되어 있을 가능성이 높습니다. 16.4 미만이면 알림은 받을 수 없고, 앱 내 공지 표시만 가능합니다.

### 3-4. 공지 수정·삭제

`/app/admin/announcements` 목록에서 각 공지의 「수정」 / 「삭제」 버튼.
**주의**: 푸시는 이미 전송된 것을 회수할 수 없습니다. 공지 본문만 수정 가능.

## 4. 대회 사진 업로드 (SmugMug)

대회 사진은 SmugMug에 업로드하면 **1시간 안에 자동으로** 홈페이지(`/gallery`)와 앱(`/app/photos`)에 표시됩니다.

### 4-1. 업로드 방법 (2가지)

#### 옵션 A: 외부 사진작가용 (인증 불필요)

링크: **https://arico.smugmug.com/upload/hqJS8f/guest**

- 사진작가에게 이 링크 하나만 공유
- 로그인 없이 드래그앤드롭 업로드 가능
- 자동으로 「Upload Gallay (Guest)」 앨범에 들어감

#### 옵션 B: 조직위 직접 업로드 (SmugMug 로그인)

1. https://media.arico.group 로그인
2. 폴더 이동: `Gyeyang Open Competition` → `2026-GyeyangOpen`
3. 원하는 앨범 클릭 (또는 새 앨범 생성)
4. 우상단 「Upload」 버튼

### 4-2. 일자별 분류 (권장)

대회 일자별로 앨범을 만들면 사이트에 자동으로 탭이 생성됩니다.

권장 앨범 이름:
- `1 Day` (5/13 수요일)
- `2 Day` (5/14 목요일)
- `3 Day` (5/15 금요일)
- `4 Day` (5/16 토요일)
- `5 Day` (5/17 일요일)
- `6 Day` (5/18 월요일)

→ 숫자 prefix를 인식해서 자동으로 순서대로 정렬됩니다.

### 4-3. 사진 캡션 입력 (선택, 권장)

각 사진의 캡션(Caption)을 입력하면 라이트박스 하단에 표시됩니다.

**입력 방법**:
1. SmugMug에서 사진 클릭
2. 우측 「i」 아이콘 → 「Edit details」
3. Caption 필드에 한·영 병기 추천: `리커브 남자 결승 / Recurve Men Finals`

### 4-4. 워터마크 설정

현재는 「No Watermarks」로 설정되어 있어 깨끗하게 표시됩니다.

**워터마크가 사진에 보이는 경우**: 사진 파일 자체에 박혀있는 워터마크입니다 (사진작가가 Lightroom 등에서 export 시 추가). SmugMug나 사이트에서는 지울 수 없으므로, **사진작가에게 워터마크 없는 원본을 다시 요청**하세요.

### 4-5. 비공개 사진 (선수용 등)

비밀번호 보호된 앨범은 사이트에 노출되지 않습니다. 예시: `Upload Gallary (admin)` 앨범. 이 앨범의 사진은 사이트에 안 나타나며, SmugMug 직접 링크로만 접근 가능합니다.

### 4-6. 자동 동기화 동작

| 시나리오 | 결과 |
|---|---|
| SmugMug에 새 사진 업로드 | 최대 1시간 후 자동 노출 |
| 즉시 반영 필요 | [§5](#5-캐시-새로고침) 캐시 새로고침 |
| 새 앨범 추가 (`2 Day` 등) | 자동으로 새 탭 생성 |
| 비밀번호 앨범 | 자동 제외 |
| 빈 앨범 | 자동 제외 |
| 사진 삭제 | 1시간 후 사이트에서도 사라짐 |
| 비디오 파일 | 자동 제외 (사진만 표시) |

## 5. 캐시 새로고침

사이트는 외부 데이터를 1시간 단위로 캐시합니다. **즉시 반영이 필요할 때**만 새로고침을 사용하세요.

### 5-1. 사진 캐시 새로고침

1. https://www.gyeyangopen.com/app/admin 접속 (관리자 로그인 필요)
2. 「빠른 작업」 카드의 **「SmugMug 사진 캐시 새로고침」** 버튼 클릭
3. 「✓ 사진 캐시 갱신 완료」 메시지 확인
4. `/gallery` 페이지 새로고침으로 반영 확인

### 5-2. 기타 캐시 (자동)

- **공지사항**: 캐시 없음 (즉시 반영)
- **선수 명단·결과**: ianseo 캐시 1시간. 종료된 대회라 변경 거의 없음
- **사진**: SmugMug 캐시 1시간

대부분의 경우 새로고침이 필요 없습니다. 사진 업로드 후 빠르게 확인해야 할 때만 사용하세요.

## 6. 관리자 권한 부여

기본적으로 회원가입한 사용자는 `athlete`(선수) 권한이며, 관리자 대시보드(`/app/admin`)에 접근할 수 없습니다.

### 6-1. 슈퍼관리자 (코드 레벨)

`src/lib/super-admin.ts`에 이메일이 등록된 사용자는 항상 관리자입니다.

- 현재 슈퍼관리자: `ndckshin@gmail.com` (그리고 `sms@arico.co.jp` 등 — 파일 직접 확인)
- 추가하려면 GitHub에서 파일을 수정해 PR 후 머지 필요

### 6-2. 일반 관리자 (Supabase DB)

다른 운영진에게 관리자 권한을 주려면 Supabase의 `profiles.role` 컬럼을 `admin`으로 변경합니다.

**방법 1: SQL Editor (Supabase 콘솔)**

1. https://supabase.com/dashboard/project/zgykozcoutixaobwkxru/sql/new
2. 다음 쿼리 실행 (이메일은 부여할 사용자의 가입 이메일):
   ```sql
   UPDATE public.profiles
   SET role = 'admin'
   WHERE id = (
     SELECT id FROM auth.users WHERE email = '대상이메일@example.com'
   );
   ```
3. 대상 사용자가 다시 로그인하면 `/app/admin` 메뉴가 노출됨

**방법 2: 사용자 관리 페이지 (슈퍼관리자만)**

1. 슈퍼관리자로 `/app/admin/users` 접속
2. 대상 사용자 검색 → 「관리자로 변경」 버튼

### 6-3. 관리자 권한 회수

같은 방법으로 `role`을 `athlete`로 되돌리면 됩니다.

## 7. 도메인·SSL·환경변수

### 7-1. 도메인

- **메인 도메인**: `www.gyeyangopen.com` (Vercel 연결)
- **별칭**: `gyeyangopen.com`, `gyeyang-open-2026.vercel.app`
- **이전 도메인**: `gyeyangopen.kr` (현재 미사용. DNS 만료 시 갱신 불필요)

SSL은 Vercel이 자동 발급·갱신하므로 별도 관리 불필요.

### 7-2. 환경변수 (Vercel)

[Vercel 환경변수 페이지](https://vercel.com/arico/gyeyang-open-2026/settings/environment-variables)에 다음이 등록되어 있어야 합니다:

| Key | 용도 | 어디서 받나 |
|---|---|---|
| `NEXT_PUBLIC_SUPABASE_URL` | Supabase 연결 URL | Supabase 콘솔 |
| `NEXT_PUBLIC_SUPABASE_ANON_KEY` | Supabase 익명 키 | Supabase 콘솔 |
| `NEXT_PUBLIC_VAPID_PUBLIC_KEY` | 푸시 알림 공개 키 | `npx web-push generate-vapid-keys` |
| `SMUGMUG_API_KEY` | SmugMug API 키 | https://api.smugmug.com/api/developer |
| `SMUGMUG_NICKNAME` | SmugMug 닉네임 (`arico`) | 고정값 |
| `SMUGMUG_ROOT_FOLDER` | 사진 폴더 경로 | `Gyeyang-Open-Competition/2026-GyeyangOpen` |

### 7-3. Supabase Edge Function 시크릿

`send-push` 함수에 필요한 시크릿:

- `VAPID_PUBLIC_KEY`
- `VAPID_PRIVATE_KEY`
- `VAPID_SUBJECT` (`mailto:admin@gyeyangopen.com`)

[Supabase 시크릿 페이지](https://supabase.com/dashboard/project/zgykozcoutixaobwkxru/functions/secrets)에서 관리. **VAPID_PRIVATE_KEY는 절대 외부에 노출되면 안 됩니다.**

### 7-4. 변경된 환경변수를 적용하려면

1. Vercel: 환경변수 추가/수정 후 **새 배포** 필요 (또는 자동으로 다음 배포 때 반영)
2. Supabase: 시크릿 변경 후 Edge Function이 자동 재기동

| nearby_places | 5 | 주변 정보 (음식점·교통 등) |
| push_subscriptions | 1 | 테스트 디바이스 1개 |

본 대회는 실제로 본 사이트를 통한 등록·문의를 받지 않았기 때문에 개인정보 보존 이슈는 거의 없습니다. **다음 대회를 위한 인프라 검증** 차원으로 이해하시면 됩니다.

### 8-2. 개인정보 보존 정책 (제안)

차기 대회에서 실제 등록을 받는다면 다음 정책을 권장합니다:

| 데이터 | 보존 기간 | 폐기 시점 |
|---|---|---|
| `profiles` (계정) | 사용자가 직접 탈퇴 시까지 | 사용자 요청 |
| `registrations` (참가신청) | 대회 종료 후 1년 | 차기 대회 시작 전 |
| `inquiries` (문의) | 답변 완료 후 6개월 | 정기 일괄 삭제 |
| `attendance` (출석) | 대회 종료 후 1년 | 차기 대회 시작 전 |
| `push_subscriptions` | 사용자 구독 해지 또는 디바이스 만료 (410 응답) | 자동 cleanup |

### 8-3. 데이터 백업

Supabase는 Pro 플랜이라 **일 단위 자동 백업**이 됩니다. 별도 작업 불필요.

수동 백업이 필요하면:
1. https://supabase.com/dashboard/project/zgykozcoutixaobwkxru/database/backups
2. 「Download backup」 버튼

### 8-4. 데이터 정리 SQL (대회 종료 후 운영진용)

대회 종료 후 6개월 뒤 등 정해진 시점에 실행 권장:

```sql
-- 답변 완료 후 6개월 지난 문의 삭제
DELETE FROM public.inquiries
WHERE status = 'replied' AND updated_at < NOW() - INTERVAL '6 months';

-- 만료된 푸시 구독 정리 (Edge Function이 자동 처리하지만 수동도 가능)
DELETE FROM public.push_subscriptions
WHERE updated_at < NOW() - INTERVAL '1 year';
```

**주의**: 삭제 전 반드시 백업을 받아두세요.

## 10. 트러블슈팅 FAQ

### Q1. 사진을 업로드했는데 사이트에 안 나타납니다

1. 1시간 기다려보기 — 자동 갱신
2. 그래도 안 나타나면 `/app/admin` → 「SmugMug 사진 캐시 새로고침」 클릭
3. SmugMug 앨범의 보안 설정이 「Public (No Password)」인지 확인
4. 사진이 1장 이상 있는지 확인 (빈 앨범은 자동 제외)

### Q2. 푸시 알림을 보냈는데 안 옵니다

1. 수신 디바이스에서 사이트의 알림 권한이 허용되어 있는지 확인 (브라우저 설정)
2. iOS는 16.4 이상이어야 PWA 푸시 가능
3. iOS의 경우 「홈 화면에 추가」된 PWA여야 함 (브라우저로 열린 상태에서는 푸시 안 옴)
4. Supabase `push_subscriptions` 테이블에 해당 사용자 행이 있는지 확인
5. Edge Function `send-push` 로그 확인 (Supabase 콘솔)

### Q3. 관리자 페이지에 접속이 안 됩니다

1. 로그인 상태 확인
2. `profiles.role` = `admin` 또는 `super-admin.ts`에 이메일이 있는지 확인
3. 로그아웃 후 다시 로그인 (세션 새로고침)

### Q4. 사이트가 안 열립니다 (500 에러 등)

1. Vercel 배포 상태 확인: https://vercel.com/arico/gyeyang-open-2026
2. 최근 배포가 실패했다면 「Promote to Production」으로 이전 배포로 롤백
3. Supabase 상태 확인: https://status.supabase.com

### Q5. ianseo 선수 명단·결과가 안 나옵니다

1. 본 사이트는 ianseo 토너먼트 28161에서 데이터를 가져옵니다
2. ianseo가 다운된 경우 사이트는 자동으로 **정적 백업(`results-2026.json`)**으로 전환됨 (메달리스트 표시)
3. 5분~1시간 후 자동 복구됨. 즉시 재시도하려면 캐시 새로고침

### Q6. 도메인이 다른 곳으로 가야 합니다 (예: 2027 별도 도메인)

1. Vercel 도메인 설정에서 새 도메인 등록
2. DNS 레코드를 Vercel이 안내한 값으로 변경
3. SSL은 자동 발급

```sql
SELECT u.email, p.role

```
